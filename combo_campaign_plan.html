⚙️ Technical Setup Checklist
  • 🛍️
    Create the Combo Product Page on Shopify

    Build a dedicated combo product page (not individual product pages). Title: "Summer Daily Duo — Anytime Lotion + SPF 50 Sunscreen" at ₹999. Add "FREE DELIVERY INCLUDED" prominently. This is where all ads will send traffic.

  • 🔌
    Meta Pixel + Conversions API — Verify Both Active

    Confirm your Pixel is firing on the new combo product page. Verify CAPI is active (Shopify Admin → Meta App → Conversions API). Without this, Meta can't optimise properly.

  • 📦
    Add Combo to Product Catalog in Meta Business Manager

    For dynamic retargeting ads to show the exact combo. Go to Commerce Manager → Catalog → Add product → ensure the ₹999 combo is listed with correct image, title, and URL.

  • 📋
    Upload Customer List for Lookalike Audience

    Export your Shopify customer list (name + email/phone) → Upload to Meta Business Manager → Audiences → Create Custom Audience from Customer List → Then create 1% Lookalike.

  • ✅
    Set Up UTM Parameters for All Ad Links

    Add UTM tags to your combo page URL so you can track which specific ad is driving purchases: utm_source=facebook&utm_medium=paid&utm_campaign=summer_daily_duo&utm_content=[ad_name]

📈 Daily Scaling Plan — Week by Week from ₹5K to ₹15K+ per day
Days 1–3
🔵 Learning Phase — Do Not Touch
Meta's AI is learning which users convert. Expected ROAS: 1.5×–3× (normal during learning). Do not change anything. Monitor daily report. KPI to watch: Add-to-cart rate should be above 3%. If it's below 1%, the creative may need review after Day 5.
Days 4–7
🔵 Early Optimisation — Observe
ROAS should climb to 2.5×–4×. Review which creative is getting the most purchases and lowest cost/purchase. Pause any creative with 0 purchases and 500+ impressions. Do NOT change budgets yet. Add 1 new creative variant if one is clearly winning (test its close sibling).
Day 8–10
🟢 First Scale — If ROAS ≥ 3.5×
If blended ROAS is at or above 3.5× after Day 7, increase budget by 20%: ₹5,000 → ₹6,000/day. Scale only the Advantage+ Broad ad set (Ad Set 1). Keep retargeting and lookalike at same budget. Monitor for 3 days before scaling again. Expected ROAS at this point: 4×–5×.
Days 11–14
🟢 Second Scale — If ROAS ≥ 4×
Scale again by 20%: ₹6,000 → ₹7,200/day. Now also test: (a) Duplicate the winning ad set with a different audience angle (e.g., 2% lookalike), (b) Add Creative 6 (comparison ad) as a fresh test. Frequency should still be below 2.5× at this point — if it's above 3×, add 2 new creatives urgently.
Days 15–21
🟠 Aggressive Scale — ₹8K–10K/day
If ROAS is stable at 4.5×+, scale every 3 days: ₹7,200 → ₹8,600 → ₹10,000/day. At this stage: (a) Launch a "sister campaign" — same combo but with a different angle (e.g., monsoon-prep, gifting), (b) Activate Threads placements, (c) Test a lower combo price (₹899 in a separate campaign) to see if volume increases offset margin reduction.
Days 22–30
🟠 Full Scale — ₹12K–15K/day Target
If all KPIs are healthy (ROAS 5×+, frequency below 3×, cost/purchase below ₹200), push to ₹12,000–15,000/day. At this scale: (a) Creative refresh every 10 days becomes mandatory, (b) Add a new combo variant (e.g., add Hair Serum to make a "Summer Complete Kit" at ₹1,499), (c) Prep for flash sale event to create a week of 6×–7× ROAS spike.
